# Enterprise Data Analytics, Integration Pipelines & BI Architecture Portfolio
### Continuous Data Engineering, Vectorized Wrangling & Advanced Financial Intelligence Frameworks

Welcome to my central production portfolio. This repository serves as an executive showcase of scalable data platform architectures, automated RESTful microservice pipelines, and advanced semantic data models that transform raw multi-table transactional warehouses into live corporate business insights.

---

## 🛠️ Global Technology Stack & Architecture Layer
- **Data Warehousing & Query Optimization:** PostgreSQL, Complex Multi-Table Joins, CTE (Common Table Expressions), Window Functions, Schema Partitioning, Keys Constraints, pgAdmin 4.
- **Backend Pipelines & Microservices Engine:** Python 3.12, FastAPI REST Gateways, Uvicorn ASGI Server, Programmatic Cloud Drivers (`pg8000`), Data Seeding Frameworks, Render Cloud Deployment.
- **Data Manipulation Layer:** Vectorized In-Memory Analytics (Pandas Core DataFrames, NumPy Arrays Calculations).
- **Business Intelligence & Presentation Front-End:** Power BI Desktop Modeling, Advanced DAX (Data Analysis Expressions), Custom Date Dimension Tables, Structural Filtering Context Loops.

## 🗺️ The 4 Pillars of Enterprise Analytics Mapped

### ⚡ Project 1: Real-Time Retail Transaction API Engine
* **Core Technology Stack:** Python 3.12, FastAPI Microservices, Uvicorn ASGI, Pandas Vectorization.
* **Architectural Scope:** Engineered a low-latency data extraction gateway routing raw database tables into custom memory buffers to serve production-ready JSON data streams. 
* **Operational Logic:** Programmed strict leakage protection rules to force active revenue variables to automatically zero out (`Net Revenue = £0.00`) whenever a record triggers a transaction `Returned` flag.
* **BI Interface Connection:** Streams optimized real-time endpoints straight into a live Power BI tabular reporting dashboard.

### 🏬 Project 2: B2B Electronics Logistics & Warehouse Health Engine
* **Core Technology Stack:** PostgreSQL Data Warehouse, Python/FastAPI Framework, In-Memory DataFrames Analytics.
* **Architectural Scope:** Integrated multi-stage active supplier freight shipments logs to calculate automated stock depletion alarm parameters directly inside the pipeline.
* **Operational Logic:** Developed a loop-free vectorized logic matrix checking current balances against safety levels to dynamically flag inventory streams (`CRITICAL RE-ORDER` vs `HEALTHY`) and track capital tied-up in stock.
* **BI Interface Connection:** Direct single-table visualization grid mapping product metrics distribution side-by-side.

### 💰 Project 3: Corporate Finance Cash-Flow & Margin Optimization Hub
* **Core Technology Stack:** Advanced DAX Engineering, Context Modification, Relational Keys Layouts.
* **Architectural Scope:** Formulated an autonomous calendar dimension partitioning transactional spending charts cleanly by chronological year-month slices.
* **Operational Logic:** Wrote complex semantic aggregations using the `CALCULATE` and `FILTER` measures engine to cleanly isolate incoming gross revenue streams from operational outgoings (OpEx, Marketing, Tax).
* **BI Interface Connection:** Target variance speedometer tracking meters evaluating monthly actual profit targets against corporate percentages.

### 🧠 Project 4: E-Commerce Customer Behavioral Intent Funnel Analytics
* **Core Technology Stack:** Nested SQL Case Expressions, Aggregate Blocks, Direct DB Import Connector Queries.
* **Architectural Scope:** Scripted conditional database logic analyzing browser session durations to isolate drop-off friction points and group user identities into high-intent segments (VIP Converters vs Cart Abandoners).
* **Visual Mapping Frontend:** Conversion funnel drop-off charts tracking exact sequence drop-offs points.
