# E-Commerce Customer Behavioral Segmentation & Funnel Analytics Platform

An analytical dashboard platform that monitors real-time user journey clickstreams from a PostgreSQL data warehouse to map conversion funnels and isolate structural drops behavior profiles.

## 🚀 Architectural Blueprint
- **Data Warehousing (SQL):** Managed transactional sessions tables schemas inside PostgreSQL.
- **Advanced Modeling:** Structured conditional data aggregates dynamically partitioning users into intent buckets (VIP Converters, Cart Abandoners, and Window Shoppers).
- **Presentation Matrix (Power BI):** Designed interactive conversion funnel drop-off charts and auditing tables dashboards.

## 📁 Repository Structure
- `schema.sql`: Contains base structures layout scripts and the production analytics query template.
- `Customer_Behavior_Dashboard.pbix`: Dynamic business intelligence visualizations workspace sheet.
